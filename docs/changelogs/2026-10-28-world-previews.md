date: 2026-10-28
title: Preview 3D Worlds before planning a mission
category: Worlds
summary: Import GLB models as 3D Worlds, inspect them in the library, and see the selected model on mission cards.
---

- Import a GLB file as a local 3D World, then select it while creating or editing a mission.
- See World thumbnails in the library and open an interactive preview to orbit, pan, and zoom around the model.
- Mission cards show the selected 3D World, with ready-to-open Santorini and 750 Railroad Ave examples in the project.

title: Clearer Download package status
category: Library
summary: See which package actions are demonstrations before activating them, and distinguish the fixed Android platform from selectable operating systems and hardware.
---

- Desktop and SkyTrack OS package cards identify illustrative versions as demos and state that no installer is attached before the action is used.
- Android is presented as the only available Mobile platform, with the provided Google Play listing kept as its action.
- The Jetson setup guide identifies the directory containing `initrd-flash` for the provided command. The flashing procedure remains prototype guidance and has not been independently validated.
